# Dashboard Cacao – nombres abreviados

Los filtros de supervisor, extensionista y técnico muestran solo el primer nombre y el primer apellido (calculado a partir de nombres en orden nombres-apellidos). Se han verificado las coincidencias de etiquetas abreviadas para evitar mezclar personas con igual etiqueta.

**ATENCIÓN:** nombre + apellido sigue siendo información personal. La aplicación y el repositorio son públicos; confirmar autorización institucional antes de publicar. No subir Excel ni PBIX originales.

La base no contiene nombres ni DNI de productores. Se agrupan comunidades pequeñas. Los indicadores siguen pendientes de validación contra las medidas DAX y no existe filtro mensual fiable.

Para actualizar GitHub, reemplazar `app.py`, `datos_publicos_personal.csv`, `README.md` y `requirements.txt`.
