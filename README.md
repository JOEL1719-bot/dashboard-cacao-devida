# Dashboard Cacao – prototipo de validación

Ejecutar `streamlit run app.py`.

Contiene 7 pestañas con gráficos interactivos y filtro por ámbito. Fuente actualizada hasta octubre 2026, pero las cifras de la hoja principal son acumulados sin fecha por productor. No son indicadores oficiales validados. **No publicar el Excel original ni PBIX**: contienen información personal. Para publicar los agregados, obtener autorización institucional.

Para publicar, subir solo `app.py`, `requirements.txt` y `datos_publicos_ambito.csv` a un repositorio público y conectar Streamlit Community Cloud.
