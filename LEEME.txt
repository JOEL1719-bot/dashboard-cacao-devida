DASHBOARD DEVIDA - VERSIÓN MODERNA Y COLORIDA

1. Descomprime este ZIP en una carpeta.
2. Instala las dependencias: pip install -r requirements.txt
3. Ejecuta: python -m streamlit run app.py
4. Abre la dirección local que aparezca en pantalla.

Esta versión incorpora tarjetas de colores, medias lunas grandes e iconos ilustrativos tipo emoji. No son imágenes fotográficas ni copias exactas del diseño conceptual.

Los arcos semicirculares son decorativos y NO representan el porcentaje de una meta.
Los indicadores utilizan el archivo CSV agregado que se incluye. Verifica la autorización institucional antes de publicar el dashboard o los datos en un repositorio público.
